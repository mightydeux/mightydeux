# 걸그룹 메이커 — 데뷔 이후 비주얼 컨셉 가이드

이 폴더는 **연습생 단계 → 데뷔 이후**로 넘어갈 때 그래픽 퀄리티를 올리기 위한 컨셉 이미지와 적용 가이드입니다.

클로드에게 이 ZIP을 주고 아래와 같이 지시하세요:

> “이 폴더의 이미지 스타일로 데뷔 이후 캐릭터, NPC, 마을/건물 배경을 바꿔줘. 
> 연습생 때는 기존 SVG를 유지하고, 데뷔 이벤트 때 이 스타일의 이미지로 교체되게 해줘. 
> 가이드 문서도 꼭 참고해.”

---

## 1. 전체 방향

- **연습생 단계**: 기존처럼 단순한 2D / SVG 스타일 유지 (프린세스 메이커 느낌)
- **데뷔 이후**: 이 폴더의 이미지처럼 **소프트 애니 + 현실감** 스타일로 전환
- 소녀 유저들이 “내가 키운 애가 진짜 아이돌이 됐다”고 느낄 수 있게, 예쁘지만 과하지 않은 현실감 유지

## 3. 클로드에게 요청할 때 추천 문장

```
이 ZIP 안의 이미지들을 참고해서 다음을 해줘:

1. 데뷔 이후 주인공 캐릭터를 이 스타일의 이미지로 교체할 수 있게 구조를 바꿔줘.
   - 연습생 때는 기존 girl.js SVG를 쓰고
   - 데뷔 이벤트 때 이미지 스프라이트로 바뀌게.

2. NPC도 이 스타일로 몇 명 추가하거나 교체해줘.

3. 마을 맵과 건물 배경도 이 분위기(소프트하고 따뜻한 한국 엔터 거리)로 맞춰줘.
   지금처럼 도트만 쓰지 말고, 배경 이미지를 쓸 수 있게 해줘.

4. UI는 아직 크게 안 바꿔도 되지만, 전체적으로 따뜻하고 부드러운 색감으로 살짝 조정해줘.

게임 로직은 최대한 유지하고, 비주얼만 이 컨셉에 맞게 바꿔줘.
```

---

## 4. 추가로 만들면 좋은 것 (나중에)

- 주인공 표정 4~5종 (기본, 미소, 놀람, 피곤, 자신감)
- 의상 3~4벌 (연습복, 일상, 무대 의상)
- 맵 타일 대신 쓸 배경 이미지 몇 장
- UI 버튼 / 창 프레임을 이 분위기에 맞게

이 가이드와 이미지를 클로드에게 주면, 구체적인 수정 방향을 잘 잡을 수 있을 거예요.

질문이 있으면 이 채팅으로 다시 물어보세요.
