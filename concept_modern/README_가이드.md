# 걸그룹 메이커 — 모던 케이팝 소녀 스타일 컨셉 가이드

이 폴더는 게임의 **전체 비주얼 방향**을 맞추기 위한 컨셉 이미지입니다.

클로드에게 이 ZIP을 주면서 아래처럼 부드럽게 전달하시면 됩니다.

---

## 클로드에게 전달할 문장 (복사해서 사용)

```
지금까지 만들어준 게임 정말 고마워.
기능은 잘 돌아가는데, 비주얼 쪽을 조금 더 다듬고 싶어서 컨셉 이미지를 준비했어.

이 ZIP 안의 이미지 스타일로 전체 비주얼을 다시 맞춰줄 수 있을까?

- 캐릭터 (주인공 + NPC)
- 맵과 건물
- 버튼, 대화창, 상태창 같은 UI

기존 SVG나 도트 스타일은 이제 쓰지 말고,
이 이미지들처럼 부드럽고 모던한 케이팝 소녀 느낌으로 바꿔줘.

노출은 적게, 소녀들이 이입하기 좋은 스타일로 부탁해.
게임 로직은 최대한 유지해줘.
```

## 전체 방향 요약

- **스타일**: 프린세스 메이커의 따뜻함 + 모던 케이팝 소녀
- **노출**: 적게 (짧은 숏팬츠 등 피함)
- **톤**: 귀엽지만 유치하지 않고, 소녀들이 이입하기 좋은 느낌
- **기존 것**: SVG 캐릭터와 도트 맵은 교체 대상

이 가이드와 이미지를 주시면 클로드가 방향을 잘 잡을 수 있을 거예요.

더 필요한 이미지(표정, 다른 의상, 추가 NPC 등)가 있으면 말씀해 주세요.
